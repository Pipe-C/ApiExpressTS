# Express TypeScript API

API REST desarrollada con Node.js, Express y TypeScript, aplicando principios de arquitectura limpia y contenedor de inyección de dependencias.

## 🚀 Tecnologías

* **Node.js** & **Express**
* **TypeScript**
* **Inyección de Dependencias** (Awilix / Custom Container)
* **DTOs** (Data Transfer Objects)
